
# Boosting Algorithms Implementation
This repository contains implementations and demonstrations of popular boosting algorithms used in machine learning. Boosting is a powerful ensemble technique that combines multiple weak learners to create a strong, high-performance model.

## Contents
- **AdaBoost:** Implementation of the Adaptive Boosting algorithm.
- **Gradient Boosting:** Understanding and implementing Gradient Boosting for regression tasks.
- **XGBoost:** Advanced implementation and parameter tuning of the eXtreme Gradient Boosting algorithm.

## Algorithms Overview

### 1. AdaBoost (Adaptive Boosting)
AdaBoost builds an ensemble by iteratively focusing on the errors made by previous weak learners (typically Decision Stumps).
* **Key concept:** Dynamically updates sample weights to pay more attention to misclassified instances.
* **Notebook focus:** Includes baseline model comparison, hyperparameter interpretation, and performance evaluation.

### 2. Gradient Boosting
Gradient Boosting trains new models to predict the residuals (errors) of the previous ensemble.
* **Key concept:** Uses gradient descent to minimize the loss function additively.
* **Notebook focus:** Training, prediction, overfitting control, and application to real-world datasets like California Housing.

### 3. XGBoost
XGBoost is a highly optimized, scalable implementation of Gradient Boosting.
* **Key concept:** Incorporates regularization (L1/L2) to prevent overfitting and supports parallel processing.
* **Notebook focus:** Deep dive into the "disciplined correction loop," parameter tuning, and evaluation best practices.
